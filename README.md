# Shopping Research System

제품 탐색을 단순 검색 결과 나열이 아닌, **재현 가능한 근거 기반 조사·검증·구매 가능성 판정**으로 수행하기 위한 표준 저장소입니다.

## 목표

- 제품 모델·품번·시즌을 정확히 식별한다.
- 핵심 사양과 판매 정보의 출처 및 신뢰도를 분리해 기록한다.
- 판매 페이지 존재와 실제 구매 가능 재고를 구분한다.
- 확인되지 않은 값은 추정하지 않고 `UNKNOWN` 또는 `DATA_NOT_READY`로 남긴다.
- 동일한 프로토콜로 후보를 재검색하고 비교할 수 있게 한다.

## Research workflow

1. `PRODUCT_RESEARCH_PROTOCOL.md` — 조사 범위와 절차 정의
2. `SOURCE_RELIABILITY.md` — 출처 신뢰도 평가
3. `SPEC_VERIFICATION.md` — 모델·사양 검증
4. `STOCK_MONITORING.md` — 옵션별 구매 가능성 확인
5. `EVIDENCE_SCHEMA.md` — 결과를 구조화해 저장

## 기본 원칙

- 모델명, 품번, 시즌이 일치하지 않는 자료를 합쳐 하나의 사양으로 만들지 않는다.
- 제조사 공식 자료와 판매자 설명을 동일한 수준의 근거로 취급하지 않는다.
- 필파워, 다운 충전량, 완제품 중량, 총장, 충전재 종류는 별도 필드다.
- 미확인 정보는 비워 두고 상태를 명시한다. 추정값을 사실처럼 기록하지 않는다.
- 재고·가격은 변동 정보이므로 확인 시각과 판매 옵션을 함께 기록한다.
- 과거 품절은 영구 제외 사유가 아니다. 재검색 시 후보를 다시 확인한다.

## Status vocabulary

| Status | Meaning |
|---|---|
| `VERIFIED` | 명시된 기준과 근거로 확인 완료 |
| `PARTIALLY_VERIFIED` | 일부 필드만 확인 |
| `CONFLICT` | 신뢰 가능한 출처 간 정보 충돌 |
| `UNKNOWN` | 정보가 발견되지 않음 |
| `DATA_NOT_READY` | 구매·비교 판단에 필요한 핵심 데이터 부족 |
| `UNAVAILABLE` | 확인 시점에 해당 옵션 구매 불가 |
| `AVAILABLE` | 확인 시점에 해당 옵션 구매 가능 |

## Scope

이 저장소는 조사 방법과 근거 기록의 표준을 정의한다. 특정 판매처의 재고나 가격을 영구적으로 보증하지 않는다.
